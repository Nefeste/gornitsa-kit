# Состояние набора

**Версия:** 1.0.0 — подготовлена 30.10.2026, ещё не слита. Тегов нет: `v1.0.0` и `v1` ставит
владелец после слияния.

**Что внутри:** загрузка в RuStore и автослияние — переиспользуемыми workflow и действиями;
ключ подписи, проверка подписи и содержимого APK — действиями для `android.yml` игр
([`README.md`](README.md)). Тесты скриптов — 14, без сети.

**Что дальше:** перевести игры по одной ([`docs/migration.md`](docs/migration.md)) — первой
«Сени» или «Анамнез»; затем, по ADR студии, — следующие кандидаты: RuStore Pay
(плагин и обёртка), снимки магазина, раздел политики.

**Ждёт владельца:**
- слить PR с набором и поставить теги `v1.0.0` и `v1`;
- ADR студии о составе набора — PR в `Nefeste/gornitsa`;
- лицензия открытого репозитория — сейчас её нет, то есть «все права защищены»;
- PR перевода игр (пути `.github/` — ваши).
